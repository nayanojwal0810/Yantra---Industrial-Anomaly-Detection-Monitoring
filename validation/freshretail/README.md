# FreshRetail validation workspace

This branch is reserved exclusively for candidate validation of FreshRetailNet-50K. It is not the final project repository.

## Ground rules
- Do not inspect, reuse, modify, or depend on any pre-existing project files or folders in this repository.
- All validation artifacts must live under `validation/freshretail/` (except this README if the user directs otherwise).
- Do not commit dataset files, credentials, personal data, or large generated artifacts.
- Every validation task must document commands run, environment, outputs, limitations, and pass/fail evidence.
- Antigravity executes only the explicitly scoped task; it must not choose a project, introduce new scope, or make decisions on behalf of the project lead.
