# Problem and Dataset Validation

This directory is an isolated validation workspace. It does not define the final project and does not replace or modify existing files outside this directory.

Use the current prompt in `validation/prompts/00_CANDIDATE_VALIDATION.md` to audit candidate problems and datasets. Do not train final models, build an application, or rewrite the repository README during validation.

The final project and its public-facing repository content will be prepared in a fresh repository after the problem, dataset, and evaluation plan are approved.
