# OULAD Project 1 — Validation Workspace

This branch is reserved only for preliminary validation of the Open University Learning Analytics Dataset (OULAD).

## Scope
- Validate the official raw dataset files.
- Produce concise, decision-focused outputs.
- Do not build the final analytics project in this branch.
- Do not modify or depend on existing repository project files.
- Do not upload the dataset or personally identifiable data.

## Dataset source
UCI Machine Learning Repository: https://archive.ics.uci.edu/dataset/349/open+university+learning+analytics+dataset
DOI: https://doi.org/10.24432/C5KK69
License: CC BY 4.0 (confirm and retain attribution for reuse).
